# STEP 07 · 더 좋게 만들기 (선택)

> STEP 06까지 끝났고 시간이 남을 때, 또는 집에서 이어서 할 때 골라 쓰세요.

## 쓰는 법

- **한 번에 하나씩만** 합니다. 두 개를 한꺼번에 시키면 뭐가 문제인지 찾기 어려워집니다.
- 하나 끝날 때마다 **"배포해줘" → 내 URL에서 확인**을 반복합니다.
- 시작하기 전에 "저장해줘"로 지금 상태를 저장해 두면, 망가져도 돌아올 곳이 있습니다.

아래 프롬프트는 그대로 복사해서 쓰면 됩니다. 괄호 부분만 내 데이터에 맞게 바꾸세요.

---

## 정렬

```
표를 (날짜) 열 기준으로 최신 것이 위로 오게 정렬해줘.
열 제목을 클릭하면 그 열 기준으로 정렬이 바뀌게 해주면 더 좋아.
```

## 검색

```
표 위에 검색칸을 하나 만들어줘.
글자를 입력하면 그 글자가 들어간 행만 표에 남게 해줘.
```

## 골라 보기 (필터)

```
(거래처) 열의 값들로 선택 메뉴를 만들어줘.
하나를 고르면 그 값에 해당하는 행만 보이게 해줘. "전체" 선택지도 넣어줘.
```

## 요약 숫자

```
표 위에 요약 칸을 만들어줘.
전체 몇 건인지, (수량) 열의 합계가 얼마인지 보여줘.
검색이나 골라 보기를 하면 보이는 행 기준으로 숫자도 같이 바뀌게 해줘.
```

## 간단한 그래프

```
(거래처)별 (수량) 합계를 막대 그래프로 보여줘.
외부 라이브러리는 쓰지 말고 HTML과 CSS만으로 그려줘.
```

## 휴대폰에서 보기 좋게

```
휴대폰으로 열었을 때 표가 잘리지 않고 보기 좋게 만들어줘.
지금 화면(PC)의 모양은 그대로 유지해줘.
```

## 입력 실수 줄이기

```
입력 폼에서 (수량)은 숫자만, (날짜)는 달력에서 고르게 해줘.
필수 칸이 비어 있으면 등록되지 않고 안내 문구가 뜨게 해줘.
```

## 새로고침 버튼

```
표 옆에 "새로고침" 버튼을 만들어줘.
누르면 시트에서 최신 데이터를 다시 불러오게 해줘.
```

## 이건 아직 하지 마세요

- **삭제 기능** — [삭제 이야기](about-delete.md)에서 다룬 이유로, 이 프로젝트에서는 만들지 않습니다.
- **로그인 없이 보이게** — 지금 구조에서는 Google 로그인이 데이터를 지키는 자물쇠입니다. 풀지 마세요.
- **표(탭) 구조 바꾸기** — 시트의 열을 바꾸면 화면 코드도 같이 고쳐야 합니다. 바꾸고 싶으면 Claude Code에 "시트의 열을 이렇게 바꾸려는데 어떤 영향이 있어?"라고 먼저 물어보세요.
