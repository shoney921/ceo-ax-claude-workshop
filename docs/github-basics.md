# GitHub이 뭔가요

> 배경지식 — 언제든 다시 읽어 보세요

## 한 줄 요약

**GitHub = 개발자들의 원드라이브.**

원드라이브에 문서를 올려 두면 어느 PC에서든 이어서 쓰죠.
GitHub은 개발자들이 **코드를 올려 두는** 원드라이브입니다.

다른 점은 딱 하나 — **누가, 언제, 무엇을 바꿨는지가 전부 기록됩니다.**
그래서 "어제까지 되던 게 오늘 안 돼요"가 생겨도 어제로 되돌릴 수 있습니다.

---

## 알아야 할 단어 4개

| 단어 | 뜻 | 원드라이브로 치면 |
|---|---|---|
| **저장소 (Repository)** | 프로젝트 하나가 들어가는 폴더 | 공유 폴더 하나 |
| **커밋 (Commit)** | "여기까지 됐다" 하고 저장하는 것 | 버전 저장 |
| **푸시 (Push)** | 내 PC의 작업을 GitHub에 올리는 것 | 클라우드에 업로드 |
| **Pages** | 저장소의 HTML을 실제 웹사이트로 띄워 주는 기능 | (원드라이브에는 없는 기능) |

여러분은 이 네 개를 **말로만** 씁니다. "배포해줘", "저장해줘"라고 하면 Claude Code가 대신 합니다.

## Markdown (마크다운)

지금 읽고 있는 이 문서의 형식입니다.
**글자 앞에 기호만 붙이면 알아서 꾸며 주는 메모 형식**이라고 생각하면 됩니다.

| 이렇게 쓰면 | 이렇게 보입니다 |
|---|---|
| `# 큰제목` | 큰 제목 |
| `## 중간제목` | 중간 제목 |
| `- 항목` | • 항목 |
| `**굵게**` | **굵게** |

개발자들이 문서를 쓰는 표준어예요. 파일 확장자는 `.md`입니다.

## README

**저장소의 첫인상이자 안내판.**
GitHub에서 폴더를 열면 `README.md`를 자동으로 펼쳐서 보여 줍니다.
이 저장소의 [README.md](../README.md)가 바로 그 예시입니다.
