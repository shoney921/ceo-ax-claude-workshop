# 마무리 정리 (공용 PC)

> 공용 PC에서 워크샵을 마칠 때 · **빠뜨리면 안 됩니다** (내 PC라면 건너뛰어도 됩니다)

지금 쓰는 PC가 여러 사람이 함께 쓰는 공용 컴퓨터라면, 계정을 남기고 가면 안 됩니다.
여러분의 GitHub 계정과 Google 계정이 남아 있으면 다음 사람이 그대로 쓸 수 있습니다.
아래를 **순서대로** 진행하세요.

---

## 1. GitHub 로그아웃

1. 브라우저에서 github.com → 오른쪽 위 프로필 사진 클릭
2. 맨 아래 **`Sign out`**

## 2. Google 로그아웃

1. 브라우저 오른쪽 위 프로필 사진 클릭
2. **`로그아웃`**
3. 이어서 **`이 기기에서 프로필 삭제`** 또는 **`동기화 사용 중지`** 까지 하면 더 확실합니다

## 3. Windows에 저장된 GitHub 로그인 정보 삭제 ⭐

이게 제일 많이 빠뜨리는 항목입니다. 처음 `push`할 때 저장된 것입니다.

1. 키보드 **`Windows`** 키 → **`자격 증명 관리자`** 입력 → 실행
2. **`Windows 자격 증명`** 클릭
3. 목록에서 **`git:https://github.com`** 을 찾습니다
4. 클릭해서 펼치고 → **`제거`**

## 4. Claude 로그아웃

1. Claude Desktop 앱 → 설정 → 계정 → 로그아웃
2. 앱을 완전히 종료합니다

> 💡 워크샵에서 연결한 Google Drive 커넥터는 여러분의 **Claude 계정**에 연결되어 있습니다.
> 로그아웃하면 작업하던 PC에서는 끊기지만, 나중에 다른 PC에서 같은 계정으로 로그인하면 그대로 커넥터가 연결되어 있습니다.

## ✅ 체크포인트

- [ ] GitHub에서 로그아웃했다
- [ ] Google에서 로그아웃했다
- [ ] 자격 증명 관리자에 `git:https://github.com` 이 없다
- [ ] Claude에서 로그아웃했다

**여러분의 작업물은 전부 GitHub에 있습니다.** 여기서 지워도 하나도 안 없어집니다.
집 PC에서 그대로 이어서 하는 방법은 [next-steps.md](next-steps.md)에 있습니다.
