# 작업 저장하기

하루 작업을 GitHub에 안전하게 남기고, 무엇이 저장됐는지 사용자에게 보여 줍니다.

## 절차

1. **올리면 안 되는 파일 확인** — `git status --short`
   실제 데이터 파일(`.xlsx`, `.csv`), API 키·시크릿, 개인정보 캡처가 있으면
   **멈추고 사용자에게 알린 뒤** `.gitignore` 추가 여부를 물어봅니다.

2. **오늘 무엇을 만들었는지 요약**해서 커밋 메시지를 짓습니다. 한국어 한 줄.
   ```
   git add -A
   git commit -m "<오늘 작업 요약>"
   git push
   ```

3. **저장 결과를 보여 줍니다.**
   ```
   git log --oneline -5
   ```

4. **사용자에게 이렇게 보고합니다:**
   > 오늘 작업이 GitHub에 저장됐습니다. 아래에서 확인할 수 있어요.
   > https://github.com/<아이디>/<저장소>
   >
   > 원드라이브 비유 기억하시죠? 방금 작업이 클라우드에 올라갔고,
   > 집 PC에서 그대로 내려받아 이어서 할 수 있습니다. (docs/next-steps.md 참고)

저장 이외의 일은 하지 않습니다 — 요청받지 않은 파일(TODO.md 등)을 만들거나 코드를 고치지 않습니다.
