# 배포하기

사용자의 작업을 GitHub에 올리고, 실제 웹 주소에서 확인하도록 안내합니다.

## 절차

1. **올리면 안 되는 파일이 섞였는지 확인합니다.**
   ```
   git status --short
   ```
   `.xlsx`, `.csv`, `.json` 키 파일, 개인정보 캡처가 보이면 **멈추고 사용자에게 알립니다.**
   `.gitignore`에 추가할지 물어보고, 사용자가 확인해 준 뒤에 진행합니다.

2. **모든 변경을 담아 커밋합니다.** 커밋 메시지는 **한국어로, 무엇이 바뀌었는지** 한 줄로 씁니다.
   ```
   git add -A
   git commit -m "<무엇을 바꿨는지 한국어 한 줄>"
   ```
   변경할 것이 없다면 커밋을 건너뛰고 3번으로 갑니다.

3. **GitHub에 올립니다.**
   ```
   git push
   ```

4. **웹 주소를 계산해서 알려줍니다.**
   ```
   git remote get-url origin
   ```
   주소가 `https://github.com/<아이디>/<저장소>` 라면 웹 주소는
   `https://<아이디>.github.io/<저장소>/` 입니다.

5. **사용자에게 이렇게 보고합니다** (두 문장 + 주소):
   > 무엇이 바뀌었는지 한 문장.
   > 아래 주소를 새로고침해서 확인해 주세요. 반영까지 1~2분 걸릴 수 있습니다.
   > https://<아이디>.github.io/<저장소>/

## 막혔을 때

- **push에서 로그인 창이 안 뜨거나 실패** → 기본 브라우저가 열려 있는지 확인하고 다시 시도합니다.
- **`rejected` / `non-fast-forward`** → 원격에 다른 변경이 있습니다. `git pull --rebase` 후 다시 push합니다.
- **주소는 뜨는데 404** → 저장소 Settings → Pages에서 Source가 `Deploy from a branch`, Branch가 `main / (root)`인지
  확인하도록 안내합니다. 처음 켠 직후라면 1~2분 기다립니다.
- **화면이 옛날 그대로** → 강력 새로고침(`Ctrl` + `Shift` + `R`)을 안내합니다.
